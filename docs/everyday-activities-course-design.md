# 日常生活英语课程设计

## 定位

“日常生活英语”面向 A1–A2 学习者，用每天真实会遇到的场景建立开口习惯。它不是把参考课件做成 PDF 阅读器，而是把场景拆成可在小程序连续完成的短课：先记词和搭配，再进入一段自然生活对话，最后换成自己的情况说出来。

课程专题编号为 `everyday-activities-english`，放在“初级英语”下，采用现有的纵向教材路径交互。

## 专题结构

| 教材 | 场景范围 | 课时数 |
| --- | --- | ---: |
| 教材一 · 晨间开始 | 醒来、洗漱、穿衣、早餐、出门 | 11 |
| 教材二 · 城市出行 | 公交、汽车、火车、出租车、步行、骑行 | 8 |
| 教材三 · 晚间居家 | 回家、做饭、用餐、收拾、放松、睡觉 | 14 |
| 教材四 · 打理家庭 | 家务、宠物、车辆、日用品、银行事务 | 10 |
| 教材五 · 保持联系 | 邮件、短信、电话、留言、信件 | 9 |
| 教材六 · 和朋友享受生活 | 生日、聚餐、电影、快餐、咖啡馆 | 5 |

共 57 节。每节都有一枚轻量本地 PNG 图标，用于小程序路径中的课时识别。

## 单节交互

每节使用现有“情景对话”结构化模板，所有内容按单个学习屏展示，点击“继续”才进入下一项：

1. 核心词汇：核心表达和一个自然衔接的搭配。
2. 情景对话：一段四句的生活交流，包含问题、回答和后续动作。
3. 自然说法：给出一个可替换内容的示例句，并明确它不是固定回答。
4. 开口练习：要求学习者用自己的时间、人物、物品和地点重新表达。
5. 小练习：从自己的真实生活中挑一件事，用本节词语说出来。
6. 实用提示：说明两个表达怎样连起来形成自然的话。
7. 延伸听读：以刚才的生活片段收尾，不再增加机械重复提示。

这种结构兼容现有的通用结构化课时发布规则，也能让未来的生活、职场或出行类标准课程复用同一套学习播放器。

## 会员规则

六本教材均属于同一个专题级会员权益。非会员只可学习整个专题路径中的前两节课，即“醒来”和“刷牙和使用牙线”；不会在每本教材中重复获得两节试听。会员解锁后可完成 57 节全部内容。

## 内容与发布

课时场景顺序参考 `lecture/` 中的日常活动课件，但词汇解释、示例句、对话和练习均为新编内容，不会向学习端投放扫描页或逐页文字。

本地重建课程与图标：

```bash
PYTHONPATH=. .venv/bin/python scripts/create_everyday_activities_english.py
```

脚本可重复执行：它会按固定专题、教材、课程和课时编号更新数据，并确保会员权益映射存在。
